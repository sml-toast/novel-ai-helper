## 三、工作流（需求 → 设计 → 开发 → 测试 → 部署）

1. **需求**：从 `doc/roadmap/roadmap.md` / PRD 取最高优先任务（当前仅 Backlog 待拍板项）。
2. **设计**：读架构/设计文档对应实测节；新表新列先写迁移条目（`server/novel-migrate.js` 的 `MIGRATIONS`）。
3. **开发**：
   - SQL 只进 `server/novel-db.js`；schema 变更走迁移，永不改已发布迁移。
   - 写操作留审计；`innerHTML` 过 `escapeHtml`；密钥永不入库（F073）。
   - 前端保持原生 ES module、无构建；新依赖需显式评估（当前仅 `@playwright/test`）。
4. **测试**：`npm test`（独立测试库，不碰开发库）；新契约先补用例再改语义。
5. **部署**：`bash scripts/novel-dev.sh` 本地预览；live 走 §五（scp 或 git pull + restart）。
