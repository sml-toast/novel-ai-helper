# 重设计方向 · 有温度的小说写作界面

> 本文是 2026-09-19「整项目推倒重来」后的**新设计方向文档**，是 `concept/index.html`（可交互概念原型）的设计意图说明。
> 它是**框架无关的**——不绑定 Next.js 还是零依赖原生栈，描述"长什么样、什么气质"，落地细节待技术栈确定后再实现。
>
> 缘起：用户对旧版前端判定"没有丝毫人性"。复盘见 `doc/retrospective/2026-09-19-rebuild-retrospective.md`，
> 核心结论——旧版是"工具仪表盘"而非"写作环境"，且多轮只在旧骨架做减法。新方向从根上换气质。

---

## 1. 设计主张（一句话）

**主角永远是文字，不是功能。进来是一片安静的稿纸，AI 是坐在你身旁的搭档，而不是满屏按钮。**

---

## 2. 七条铁律落地

| 维度 | 旧版（被否） | 新方向 |
|---|---|---|
| 主角 | 满屏功能按钮 | 稿纸本身，AI 退到身旁搭档位 |
| 排版 | 通用无衬线（冷） | 文学衬线 `Noto Serif SC` + `Playfair Display` 斜体标题；正文 18px / 行高 2.0 |
| 底色 | 纯白 / 浅灰平铺 | 暖纸渐变 + SVG 微噪点 + 顶部暖光晕（**绝无纯白**） |
| 配色 | 无主次 | 70 暖纸 / 20 墨色玻璃面 / 10 暖赭石强调色（70-20-10） |
| 记忆点 | 无 | **情绪光**：随正文情绪渐变的背景色温与指示灯 |
| 移动端 | 塌缩混乱 | 单栏 + 左轨/搭档转抽屉 + 右下浮动"搭档"按钮 |
| 反馈 | 无 | 保存轻柔提示、续写"正在思考"呼吸点、出错保留输入高亮而非清空 |

---

## 3. 记忆点：写作时的「氛围光」

界面真的"有情绪"——根据当前章节情绪（从正文关键词 sentiment 推断）实时渐变背景色温：

- **暖**（笑/光/暖/家…）→ 暖橙光晕
- **静**（夜/雨/眠/深…）→ 青蓝冷光
- **紧张**（逃/战/血/暗…）→ 赭红微震
- **沉思**（想/忆/旧/梦…）→ 紫灰柔光

实现要点（原型已验证）：`--mood-h`（色相）由 JS 读取正文关键词驱动，CSS 用 `transition` 做柔和过渡，
`prefers-reduced-motion` 下取消动效只保留静态配色。

---

## 4. 关键界面元素（原型 `concept/index.html`）

- **稿纸区**：最大留白、文学衬线正文、行高 2.0；光标处无干扰工具。
- **搭档侧（墨笺）**：AI 以"搭档"身份出现，提供"让墨笺续写 / 润色 / 找伏笔"等少量有温度的动作，默认收起为抽屉/浮动按钮。
- **顶栏极简**：仅书名 + 情绪灯 + 一个"搭档"入口；所有管理功能（知识库/大纲/发布/配置）下钻到次级视图，不抢首屏。
- **保存反馈**：右下角轻柔"已存"提示，2 秒淡出；不弹窗、不打断。
- **续写态**：搭档区显示三点呼吸动效 + 打字流式输出，营造"正在帮你写"的存在感。

---

## 5. 交互与无障碍底线

- 触摸目标 ≥ 44×44px，间距 ≥ 8px。
- 所有交互元素可见焦点态；语义化 `nav/main/section/article`；键盘可达一切。
- 异步操作必有加载态 + 错误态，且**出错保留输入、仅高亮错误**。
- 尊重 `prefers-reduced-motion`；首屏以下懒加载。

---

## 6. 待定（技术栈未选）

- 现代化栈（Next.js 14 + Tailwind + shadcn/ui）vs 保留零依赖原生栈 —— 用户尚未拍板。
- 本原型为框架无关 HTML，无论哪种栈都可照此气质落地；确定后转为对应实现。
- 情绪光的关键词词典、色相映射表、过渡时长需在实现阶段细化并写入设计 token。
