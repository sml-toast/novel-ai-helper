## 五、远期想法池（未立项、未评估工作量，仅记录方向）

1. **端到端加密云备份**：解决主密钥 + 库文件异地容灾；须评审与 F073 密钥安全目标的兼容性。
2. **AI provider 插件化**：多供应商并存、按任务类型路由模型（润色用本地、构思用云端强模型）。
3. **对话式改稿**：在流式输出（F082）之上叠加多轮会话记忆。
4. **真实发布平台对接**：替换 `simulatePublish` 为真实 provider（逐平台单独立项）。
5. **朗读 / 语音输入**：浏览器 Speech API 零依赖起步。
6. **多语言界面**：UI 文案集中化后低成本支持。
7. **卷（volumes）实体**：长篇小说卷→章→场景三层结构（schema v7 当前未含 volumes 表）。
8. **移动端适配**：响应式布局深化（当前仅桌面优先）。

## 六、推进纪律（沿用设计文档经验教训）

1. **无测试保护不改契约**：任何 API 语义变更先补契约用例。
2. **新表新列一律走迁移**：追加 `MIGRATIONS` 条目，永不修改已发布迁移；迁移失败即启动失败是特性。
3. **版本表与审计表是高频路径禁区**：自动保存/自动提及扫描不得写这两张表。
4. **零依赖红线先实测再下结论**：bigram、SSE、scrypt、busy_timeout 等结论来自一次性探针脚本。
5. **密钥永不入库**：文档、代码、测试、提交信息一律不得出现真实密钥；出现即按 F073 处置。
6. **工程化方向**：保持零运行时依赖、前端无构建；新增依赖需显式评估（当前仅 `@playwright/test` 一个 devDep）。
